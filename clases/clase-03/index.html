1 | Representación

Búsqueda en grafos

Un problema de búsqueda puede representarse como un grafo: los nodos son estados posibles y las aristas son conexiones o movimientos entre esos estados. BFS utiliza esa representación para recorrer el grafo por capas.

Definición. Un grafo se expresa como G = (V, E), donde V es el conjunto de vértices o nodos y E es el conjunto de aristas o conexiones entre nodos.

2 | Formulación

Problema de búsqueda

El objetivo es encontrar una secuencia de nodos que conecte el punto de partida con el estado objetivo. En el grafo de ejemplo, se desea llegar desde A hasta M.

Nodo inicial

Punto desde el cual comienza la búsqueda. En el ejemplo: A.

Nodo objetivo

Estado que se quiere encontrar. En el ejemplo: M.

Conexiones

Movimientos posibles entre estados.

Regla de desempate

Criterio usado cuando existen varias alternativas en el mismo nivel.

3 | Estrategia

Breadth-First Search

Breadth-First Search, o búsqueda en amplitud, explora primero los nodos más cercanos al inicio. Recorre el grafo por niveles antes de avanzar a una capa más profunda.

Regla de oro. BFS no profundiza primero: expande la frontera por capas.

4 | Selección

Regla de desempate

BFS determina que se exploran primero los nodos más cercanos al inicio. Si varios nodos están en el mismo nivel, se aplica una regla de desempate. En estos ejemplos se usa orden alfabético ascendente.

5 | Ejemplo resuelto

Encontrar M desde A

Con nodo inicial A, nodo objetivo M y orden alfabético ascendente, BFS visita todos los nodos de una capa antes de pasar a la siguiente.

NivelNodosOrden acumulado
0AA
1B, C, DA -> B -> C -> D
2E, F, G, H, IA -> B -> C -> D -> E -> F -> G -> H -> I
3J, K, LA -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L
4MA -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L -> M

6 | Distinción

Orden de exploración y camino solución

BFS puede visitar muchos nodos antes de llegar al objetivo. El orden de exploración muestra la secuencia de visita; el camino solución muestra solamente la ruta que conecta A con M.

Orden de exploración

A -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L -> M

Camino solución

A -> B -> F -> K -> M

7 | Memoria del algoritmo

Cola, frontera y visitados

BFS usa una cola o queue. Una cola sigue el principio FIFO: primero en entrar, primero en salir. La cola conserva la frontera de búsqueda: nodos descubiertos que todavía deben explorarse.

MomentoColaAcción
Inicio[A]Se encola el nodo inicial.
Expandir A[B, C, D]Se agregan los vecinos de A.
Expandir B[C, D, E, F]B sale de la cola; E y F entran al final.
Expandir C[D, E, F, G]C sale de la cola; G entra al final.
Expandir D[E, F, G, H, I]D sale de la cola; H e I entran al final.

En grafos se mantiene un conjunto de visitados. Un nodo ya visitado no se vuelve a encolar ni a explorar; así se evita repetir trabajo y quedar atrapado en ciclos.

8 | Alcance

BFS y la ruta más corta

En grafos no ponderados, BFS garantiza encontrar una ruta con el menor número de aristas desde el nodo inicial hasta el objetivo. Si las aristas tienen costos diferentes, el menor número de pasos no siempre equivale al menor costo.

Cuidado. Ruta más corta significa menor número de aristas solo cuando el grafo no está ponderado.

9 | Práctica

Procedimiento manual para BFS

  1. Identifica el nodo inicial.
  2. Identifica el nodo objetivo.
  3. Define la regla de desempate.
  4. Crea una cola e inserta el nodo inicial.
  5. Marca el nodo inicial como visitado.
  6. Extrae el primer nodo de la cola.
  7. Verifica si ese nodo es el objetivo.
  8. Identifica sus vecinos no visitados.
  9. Ordénalos con la regla de desempate.
  10. Agrega los vecinos al final de la cola y márcalos como visitados.
  11. Repite hasta encontrar el objetivo o hasta que la cola quede vacía.

10 | Síntesis

Ideas clave

  • Un grafo puede explorarse por profundidad o por amplitud.
  • BFS recorre primero los nodos más cercanos al inicio.
  • La cola conserva la frontera de búsqueda.
  • El orden de los sucesores modifica el orden de exploración.
  • En grafos es necesario controlar los nodos visitados.
  • El orden de exploración no es necesariamente el camino solución.
  • En grafos no ponderados, BFS encuentra una ruta con el menor número de aristas.

1 | Representation

Search in graphs

A search problem can be represented as a graph: nodes are possible states and edges are connections or moves between states. BFS uses that representation to traverse the graph layer by layer.

Definition. A graph is expressed as G = (V, E), where V is the set of vertices or nodes and E is the set of edges or connections between nodes.

2 | Formulation

Search problem

The goal is to find a sequence of nodes that connects the starting point to the goal state. In the example graph, the search goes from A to M.

Initial node

Point where the search begins. In the example: A.

Goal node

State we want to find. In the example: M.

Connections

Possible moves between states.

Tie-break rule

Criterion used when there are several alternatives in the same level.

3 | Strategy

Breadth-First Search

Breadth-First Search explores the nodes closest to the start first. It traverses the graph by levels before moving to a deeper layer.

Golden rule. BFS does not go deep first: it expands the frontier by layers.

4 | Selection

Tie-break rule

BFS determines that the nodes closest to the start are explored first. If several nodes are in the same level, a tie-break rule is applied. These examples use ascending alphabetical order.

5 | Solved example

Find M from A

With initial node A, goal node M, and ascending alphabetical order, BFS visits every node in one layer before moving to the next one.

3J, K, LA -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L
4MA -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L -> M

6 | Distinction

Exploration order and solution path

BFS may visit many nodes before reaching the goal. The exploration order shows the visiting sequence; the solution path shows only the route that connects A to M.

Exploration order

A -> B -> C -> D -> E -> F -> G -> H -> I -> J -> K -> L -> M

Solution path

A -> B -> F -> K -> M

7 | Algorithm memory

Queue, frontier, and visited nodes

BFS uses a queue. A queue follows the FIFO principle: first in, first out. The queue stores the search frontier: discovered nodes that still need to be explored.

MomentQueueAction
Start[A]Enqueue the initial node.
Expand A[B, C, D]Add A's neighbors.
Expand B[C, D, E, F]B leaves the queue; E and F enter at the end.
Expand C[D, E, F, G]C leaves the queue; G enters at the end.
Expand D[E, F, G, H, I]D leaves the queue; H and I enter at the end.

In graphs, BFS keeps a set of visited nodes. A visited node is not enqueued or explored again; this avoids repeated work and prevents cycles from trapping the search.

8 | Scope

BFS and the shortest path

In unweighted graphs, BFS guarantees a route with the minimum number of edges from the initial node to the goal. If edges have different costs, the smallest number of steps is not always the lowest cost.

Careful. Shortest path means the fewest edges only when the graph is unweighted.

9 | Practice

Manual procedure for BFS

  1. Identify the initial node.
  2. Identify the goal node.
  3. Define the tie-break rule.
  4. Create a queue and insert the initial node.
  5. Mark the initial node as visited.
  6. Remove the first node from the queue.
  7. Check whether that node is the goal.
  8. Identify its unvisited neighbors.
  9. Order them using the tie-break rule.
  10. Add the neighbors to the end of the queue and mark them as visited.
  11. Repeat until the goal is found or the queue becomes empty.

10 | Synthesis

Key ideas

  • A graph can be explored by depth or by breadth.
  • BFS visits the nodes closest to the start first.
  • The queue stores the search frontier.
  • The successor order changes the exploration order.
  • Graphs require controlling visited nodes.
  • The exploration order is not necessarily the solution path.
  • In unweighted graphs, BFS finds a route with the fewest edges.
Summary phrase. BFS does not go deep first: it expands the frontier by layers.
