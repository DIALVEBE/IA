1 | Mejorar

Optimización en inteligencia artificial

En inteligencia artificial no siempre basta con encontrar una solución. En muchos problemas existen muchas respuestas posibles y la pregunta importante es cuál de ellas es mejor según un criterio.

Idea central. Buscar es encontrar una solución. Optimizar es intentar encontrar la mejor solución o una suficientemente buena.

Rutas

Minimizar distancia, costo o tiempo.

Modelos

Minimizar el error de predicción.

Videojuegos

Maximizar la puntuación de un agente.

Horarios

Reducir conflictos entre clases, salones y recursos disponibles.

3 | Estrategia local

Hill Climbing

Hill Climbing observa soluciones cercanas y se mueve hacia una que mejore el valor actual.

Regla. Si un vecino cercano es mejor que la solución actual, el algoritmo se mueve hacia ese vecino.

5 | Implementación

Código completo

Este código implementa Hill Climbing sobre la función de altura. El botón Copiar permite llevarlo directamente al editor.

def altura(x):
    return -(x - 7)**2 + 50


posicion = 0

while True:
    actual = altura(posicion)
    izquierda = altura(posicion - 1)
    derecha = altura(posicion + 1)

    print(f"x={posicion:2} | altura={actual:2}")

    if derecha > actual:
        posicion += 1
    elif izquierda > actual:
        posicion -= 1
    else:
        break

print("Mejor solucion encontrada")
print(f"x = {posicion}")
print(f"altura = {altura(posicion)}")

6 | Vecinos

Espacio de búsqueda

El espacio de búsqueda contiene todas las soluciones posibles. Hill Climbing explora principalmente soluciones cercanas a la actual.

En una línea

Los vecinos de x son x - 1 y x + 1.

En un tablero

Los vecinos pueden ser arriba, abajo, izquierda y derecha.

En rutas

Un vecino puede aparecer al intercambiar dos ciudades.

En horarios

Un vecino puede cambiar una clase de salón o franja.

7 | Riesgo

Óptimos locales y globales

Un óptimo local es mejor que sus vecinos cercanos, pero no necesariamente es la mejor solución de todo el problema.

Límite. Hill Climbing no garantiza encontrar siempre el óptimo global.

9 | Aprendizaje

Optimización y Machine Learning

Entrenar un modelo puede verse como un problema de optimización: se ajustan parámetros para reducir el error.

Conexión. Hill Climbing no suele entrenar redes neuronales modernas, pero ayuda a entender la idea de evaluar parámetros y buscar valores mejores.

10 | Metaheurísticas

Más allá de Hill Climbing

Los óptimos locales motivan estrategias que exploran más allá del vecino inmediato.

Simulated Annealing

Puede aceptar temporalmente movimientos peores para escapar de una cima local.

Algoritmos genéticos

Mantienen una población de soluciones, seleccionan, cruzan y mutan candidatos.

Random Restart

Repite Hill Climbing desde diferentes inicios.

Otras metaheurísticas

Buscan equilibrar explotación de regiones buenas y exploración de regiones nuevas.

11 | Práctica

Actividad

Modifica el ejemplo original para que la posición inicial sea aleatoria, muestre vecinos, indique la decisión tomada, cuente movimientos y ejecute varios reinicios.

import random

def altura(x):
    return -(x - 7)**2 + 50

mejor_posicion = None
mejor_altura = float("-inf")

for intento in range(5):
    posicion = random.randint(-5, 12)
    movimientos = 0

    while True:
        actual = altura(posicion)
        izquierda = altura(posicion - 1)
        derecha = altura(posicion + 1)

        if derecha > actual:
            posicion += 1
            movimientos += 1
        elif izquierda > actual:
            posicion -= 1
            movimientos += 1
        else:
            break

    if altura(posicion) > mejor_altura:
        mejor_posicion = posicion
        mejor_altura = altura(posicion)

print(mejor_posicion, mejor_altura)

Idea central

Un sistema de IA optimiza aquello que definimos como objetivo. Por eso la función objetivo no es un detalle técnico: define qué comportamiento considerará mejor el sistema.

  • Optimizar requiere representar soluciones candidatas.
  • La función objetivo mide calidad.
  • Hill Climbing mejora usando vecinos.
  • El punto inicial puede cambiar el resultado.
  • Explotar y explorar deben equilibrarse.

In artificial intelligence, finding one solution is not always enough. Many problems have many possible answers, and the important question is which one is better according to a criterion.

Core idea. Searching means finding a solution. Optimizing means trying to find the best solution or one that is good enough.

3 | Local strategy

Hill Climbing

Hill Climbing looks at nearby solutions and moves toward one that improves the current value.

Rule. If a nearby neighbor is better than the current solution, the algorithm moves to that neighbor.

5 | Implementation

Complete code

This code implements Hill Climbing over the height function. The Copy button sends it directly to the editor.

def height(x):
    return -(x - 7)**2 + 50


position = 0

while True:
    current = height(position)
    left = height(position - 1)
    right = height(position + 1)

    print(f"x={position:2} | height={current:2}")

    if right > current:
        position += 1
    elif left > current:
        position -= 1
    else:
        break

print("Best solution found")
print(f"x = {position}")
print(f"height = {height(position)}")

6 | Neighbors

Search space

The search space contains all possible solutions. Hill Climbing mainly explores solutions near the current one.

... 0 1 2 3 4 5 6 7 8 ... -> 1 14 25 34 41 46 49 50 49 ...

On a line

The neighbors of x are x - 1 and x + 1.

On a board

Neighbors may be up, down, left, and right.

In routes

A neighbor may appear by swapping two cities.

In schedules

A neighbor may change a class to another room or time slot.

7 | Risk

Local and global optima

A local optimum is better than nearby solutions, but it is not necessarily the best solution in the whole problem.

Limit. Hill Climbing does not guarantee that it will always find the global optimum.

8 | Exploration

Random restarts

A simple improvement is to run Hill Climbing several times from different starting positions and keep the best result.

9 | Learning

Optimization and Machine Learning

Training a model can be seen as an optimization problem: parameters are adjusted to reduce error.

Connection. Hill Climbing is not usually used to train modern neural networks, but it helps understand the idea of evaluating parameters and searching for better values.

10 | Metaheuristics

Beyond Hill Climbing

Local optima motivate strategies that explore beyond the immediate neighbor.

Simulated Annealing

Can temporarily accept worse moves to escape a local peak.

Genetic algorithms

Keep a population of solutions, then select, crossover, and mutate candidates.

Random Restart

Runs Hill Climbing again from different starting points.

Other metaheuristics

Seek a balance between exploiting good regions and exploring new ones.

11 | Practice

Activity

Modify the original example so the starting position is random, neighbors are printed, each decision is shown, moves are counted, and several restarts are executed.

import random

def height(x):
    return -(x - 7)**2 + 50

best_position = None
best_height = float("-inf")

for attempt in range(5):
    position = random.randint(-5, 12)
    moves = 0

    while True:
        current = height(position)
        left = height(position - 1)
        right = height(position + 1)

        if right > current:
            position += 1
            moves += 1
        elif left > current:
            position -= 1
            moves += 1
        else:
            break

    if height(position) > best_height:
        best_position = position
        best_height = height(position)

print(best_position, best_height)

12 | Closing

Central idea

An AI system optimizes what we define as the objective. That is why the objective function is not a small technical detail: it defines what behavior the system will consider better.

  • Optimization requires representing candidate solutions.
  • The objective function measures quality.
  • Hill Climbing improves using neighbors.
  • The starting point can change the result.
  • Exploitation and exploration must be balanced.
