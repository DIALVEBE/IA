1 | Mundo real

Incertidumbre en inteligencia artificial

La inteligencia artificial no siempre opera en mundos perfectamente conocidos. En problemas reales, un sistema puede tener información incompleta, ambigua, ruidosa o probabilística.

Pregunta central. ¿Qué tan probable es que una hipótesis sea verdadera dadas las evidencias disponibles?

Vehículo autónomo

Un objeto detectado puede ser una persona, una sombra o una señal parcialmente oculta.

Diagnóstico médico

Fiebre y tos no identifican una sola enfermedad con certeza absoluta.

Fraude

Una transacción extraña puede ser fraude o una compra legítima poco común.

Robot

Un sensor puede detectar un obstáculo inexistente o fallar ante uno real.

2 | Representación

Probabilidad

Una probabilidad representa un grado de creencia o posibilidad entre 0 y 1.

0 <= P(A) <= 1
0 imposible0.5 incierto1 seguro
ProbabilidadInterpretación aproximada
0.10Muy poco probable
0.50Tan probable como improbable
0.80Bastante probable
0.99Extremadamente probable, pero no certeza absoluta
Precisión conceptual. Una probabilidad de 70 % no significa que el evento esté 70 % ocurrido; significa que existe incertidumbre sobre si ocurrirá.

3 | Lenguaje probabilístico

Conceptos fundamentales

Evento

Algo que puede ocurrir: lluvia, fraude, enfermedad o una alarma.

Prior

Creencia antes de observar nueva evidencia. Ejemplo: P(fraude) = 0.01.

Evidencia

Información observada: una palabra en un correo, un resultado positivo o un beep.

Likelihood

Compatibilidad de la evidencia con una hipótesis: P(evidencia | hipótesis).

Posterior

Nueva creencia después de observar evidencia: P(hipótesis | evidencia).

Condicional

El símbolo | se lee como “dado que”. P(A | B) es la probabilidad de A dado B.

4 | Actualización

Teorema de Bayes

Bayes permite actualizar una creencia cuando aparece nueva evidencia.

P(H | E) = P(E | H)P(H) / P(E)

5 | Ejemplo secuencial

Las tres cajas

Imagina que alguien escoge una caja al azar, pero no te dice cuál fue. Las tres cajas representan tres hipótesis posibles: A, B o C. Al inicio no tienes una razón para preferir una sobre otra, por eso empiezan con la misma probabilidad.

Las cajas son diferentes porque su composición interna no es la misma: la caja A tiene más monedas de oro, la caja B está más balanceada y la caja C casi siempre entrega plata. No observas la caja directamente; solo observas las monedas que van saliendo.

MomentoABC
Antes de observar33.33 %33.33 %33.33 %
Después de oro58.33 %33.33 %8.33 %
Después de oro, oro74.24 %24.24 %1.52 %
Después de oro, oro, plata58.33 %38.10 %3.57 %
Lectura. Si aparece una moneda de oro, la caja A se vuelve más probable porque esa evidencia era más esperable bajo A. Si después aparece plata, B gana peso porque producir plata es más compatible con B que con A.
def actualizar(creencias, probabilidades_evidencia):
    no_normalizadas = {}

    for hipotesis in creencias:
        no_normalizadas[hipotesis] = (
            creencias[hipotesis] * probabilidades_evidencia[hipotesis]
        )

    total = sum(no_normalizadas.values())

    return {
        hipotesis: valor / total
        for hipotesis, valor in no_normalizadas.items()
    }

6 | Tasa base

Una prueba médica que acierta el 95 %

Si una enfermedad afecta al 1 % de la población, un resultado positivo no implica automáticamente 95 % de probabilidad de enfermedad.

P(enfermedad | +) = 95 / (95 + 495) ≈ 16.1 %
Idea clave. Las probabilidades previas importan. Ignorar la tasa base puede producir conclusiones equivocadas.

7 | Clasificación

Detector de spam

La palabra “premio” puede ser evidencia para estimar si un correo es spam.

P(spam | "premio") = (0.80 x 0.30) / ((0.80 x 0.30) + (0.05 x 0.70)) ≈ 87.27 %

Si aparecen varias evidencias, Naive Bayes introduce una suposición simplificadora: las características son condicionalmente independientes dada la clase.

P(premio, urgente | spam) ≈ P(premio | spam) x P(urgente | spam) 
p_spam = 0.30
p_no_spam = 0.70

p_premio_spam = 0.80
p_premio_no_spam = 0.05

posterior = (
    p_premio_spam * p_spam
) / (
    p_premio_spam * p_spam
    + p_premio_no_spam * p_no_spam
)

Robot con sensor imperfecto

Antes del sensor, P(obstáculo) = 0.20. Si el sensor emite beep, con P(beep | obstáculo) = 0.90 y P(beep | no obstáculo) = 0.10:

P(obstáculo | beep) = 0.18 / (0.18 + 0.08) ≈ 69.23 %

También podemos estudiar eventos inciertos con simulaciones.

import random

probabilidad_lluvia = 0.30
dias = 10_000
dias_con_lluvia = 0

for _ in range(dias):
    if random.random() < probabilidad_lluvia:
        dias_con_lluvia += 1

frecuencia = dias_con_lluvia / dias

Lectura. La frecuencia simulada debería acercarse a 0.30, aunque no será exactamente igual en cada ejecución.

12 | Cierre

Idea central

Una IA inteligente no necesita saber todo con certeza. Necesita representar lo que no sabe, usar evidencia disponible, actualizar creencias, estimar riesgos y tomar decisiones razonables.

  • La incertidumbre no es un error: es parte del problema.
  • Bayes conecta creencias previas, evidencia y creencias posteriores.
  • Una probabilidad alta no significa certeza.
  • Inferir no es lo mismo que decidir.

1 | Real world

Uncertainty in artificial intelligence

Artificial intelligence does not always operate in perfectly known worlds. In real problems, a system may face incomplete, ambiguous, noisy, or probabilistic information.

Central question. How likely is a hypothesis to be true given the available evidence?

Autonomous vehicle

A detected object may be a person, a shadow, or a partially hidden sign.

Medical diagnosis

Fever and cough do not identify one disease with absolute certainty.

Fraud

An unusual transaction may be fraud or a rare legitimate purchase.

Robot

A sensor may detect a nonexistent obstacle or miss a real one.

2 | Representation

Probability

A probability represents a degree of belief or possibility between 0 and 1.

0 <= P(A) <= 1
0 impossible0.5 uncertain1 certain
ProbabilityApproximate interpretation
0.10Very unlikely
0.50As likely as unlikely
0.80Quite likely
0.99Extremely likely, but not absolute certainty
Conceptual precision. A probability of 70% does not mean that the event is 70% completed; it means there is uncertainty about whether it will occur.

3 | Probabilistic language

Fundamental concepts

Event

Something that may occur: rain, fraud, disease, or an alarm.

Prior

Belief before observing new evidence. Example: P(fraud) = 0.01.

Evidence

Observed information: a word in an email, a positive test, or a beep.

Likelihood

Compatibility of the evidence with a hypothesis: P(evidence | hypothesis).

Posterior

New belief after observing evidence: P(hypothesis | evidence).

Conditional

The symbol | is read as “given”. P(A | B) is the probability of A given B.

4 | Updating

Bayes' theorem

Bayes lets us update a belief when new evidence appears.

P(H | E) = P(E | H)P(H) / P(E)

5 | Sequential example

The three boxes

Imagine that someone chooses one box at random but does not tell you which one it was. The three boxes represent three possible hypotheses: A, B, or C. At the beginning, there is no reason to prefer one over another, so they start with the same probability.

The boxes are different because their internal composition is not the same: box A contains more gold coins, box B is more balanced, and box C almost always produces silver. You do not observe the box directly; you only observe the coins that come out.

MomentABC
Before observing33.33%33.33%33.33%
After gold58.33%33.33%8.33%
After gold, gold74.24%24.24%1.52%
After gold, gold, silver58.33%38.10%3.57%
Reading. If a gold coin appears, box A becomes more likely because that evidence was more expected under A. If silver appears later, B gains weight because producing silver is more compatible with B than with A.
def update(beliefs, evidence_probabilities):
    unnormalized = {}

    for hypothesis in beliefs:
        unnormalized[hypothesis] = (
            beliefs[hypothesis] * evidence_probabilities[hypothesis]
        )

    total = sum(unnormalized.values())

    return {
        hypothesis: value / total
        for hypothesis, value in unnormalized.items()
    }

12 | Closing

Central idea

An intelligent AI system does not need to know everything with certainty. It needs to represent what it does not know, use available evidence, update beliefs, estimate risks, and make reasonable decisions.

  • Uncertainty is not an error: it is part of the problem.
  • Bayes connects prior beliefs, evidence, and posterior beliefs.
  • A high probability does not mean certainty.
  • Inference is not the same as decision-making.
