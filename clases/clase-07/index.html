1 | Inputs and actions

What decision should Neurito make?

Neurito has three needs, each represented by a number between 0 and 1. Hunger and boredom grow as their values rise; energy works the other way around: low energy means tiredness. The network receives these measurements and predicts one of three actions.

H

Hunger

0 = not hungry
1 = very hungry

E

Energy

0 = exhausted
1 = full of energy

B

Boredom

0 = not bored
1 = very bored

For example, [0.75, 0.20, 0.40] means high hunger, low energy, and moderate boredom. Which action should take priority? The examples use a simple policy: compare hunger, tiredness (1 - energy), and boredom; choose the strongest need.

2 | Weighted sum

What does one artificial neuron calculate?

A neuron multiplies each input by a weight, adds a bias, then transforms the result with an activation function. Weights control each input's influence; bias shifts the sum.

z = x₁w₁ + x₂w₂ + x₃w₃ + b
ReLU(z) = max(0, z)

With inputs 0.8, 0.2, 0.5; weights 0.7, -0.5, 0.3; and bias 0.1:

z = 0.8×0.7 + 0.2×(-0.5) + 0.5×0.3 + 0.1 = 0.71
ReLU(0.71) = 0.71

This 0.71 is an activation, not a 71% chance of eating. One neuron has not chosen an action; the network needs multiple neurons and three output values.

hunger, energy, boredom = 0.8, 0.2, 0.5
w1, w2, w3, bias = 0.7, -0.5, 0.3, 0.1
z = hunger * w1 + energy * w2 + boredom * w3 + bias
activation = max(0, z)
print(activation)  # 0.71

3 | 3 → 6 → 3

How are neurons connected?

Neurito has three inputs, six hidden neurons, and three output neurons. Each hidden neuron combines the inputs with its own weights and bias, then applies ReLU. The output layer scores Eat, Sleep, and Play.

ParameterShapeMeaning
W1(3, 6)3 inputs to 6 hidden neurons
b1(1, 6)Bias for each hidden neuron
W2(6, 3)6 hidden neurons to 3 outputs
b2(1, 3)Bias for each output

Weights start with small random values. The network has no useful learned behavior yet: training must adjust weights and biases from examples.

4 | Prediction

From needs to action: forward propagation

Forward propagation carries input through the layers. In NumPy, @

z1 = data @ W1 + b1
a1 = relu(z1)
z2 = a1 @ W2 + b2
probabilities = softmax(z2)
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)

If the outputs are Eat 0.70, Sleep 0.20, and Play 0.10, the model selects Eat because it has the largest value. These are model probabilities, not guarantees or measures of hunger. argmax selects the index of the largest output.

Two different jobs: ReLU adds a non-linear transformation in the hidden layer; Softmax makes the final scores comparable.

5 | Learning from examples

How does training change the network?

The project generates 3,000 synthetic rows of random needs. A simple policy creates target labels by comparing hunger, tiredness (1 - energy), and boredom. This is what the network practices reproducing; the label rule is not the game's action-selection code.

np.random.seed(42)
X = np.random.rand(3000, 3)
needs = np.column_stack((X[:, 0], 1 - X[:, 1], X[:, 2]))
y = np.argmax(needs, axis=1)

The seed makes the sample repeatable. If energy is 0.1, tiredness is 0.9; the target is Sleep when 0.9 is the largest priority. Cross-entropy loss measures probability assigned to the correct answer. Backpropagation uses derivatives and the chain rule to calculate parameter changes; gradient descent updates weights to reduce loss.

w_new = w_old - η × ∂L/∂w

The learning rate η controls step size, not a percentage of information learned. One epoch is a pass through the examples. The reference uses 1,200 epochs with full-batch updates.

6 | Test on new cases

What does high accuracy tell us?

After training, the model predicts 1,000 newly generated situations. Predictions are compared with labels from the same synthetic policy.

test_data = np.random.rand(1000, 3)
expected = label_policy(test_data)
predicted = np.argmax(predict(test_data), axis=1)
accuracy = np.mean(predicted == expected)
print(f"Accuracy: {accuracy:.2%}")

99.4% accuracy would mean 994 matches out of 1,000 test cases. It shows how well the model imitates this policy on new synthetic cases. It does not establish general intelligence, knowledge of a real pet, or that the policy itself is appropriate.

Evaluation depends on the target. High accuracy can mean the model learned a simplistic rule very well.

7 | Prediction becomes visible

Connect the model to Neurito

Pygame displays need bars, prediction scores, and sprite animation. The predicted action chooses Eat, Sleep, or Play. Frames change every 500 ms. Images visualize a decision; they are not neural-network training data.

The visual neutral state is a separate interface rule: hunger < 0.4, energy > 0.6, and boredom < 0.4. Neutral is not a fourth output; the network still predicts only three actions.

def visible_state(hunger, energy, boredom, prediction):
    if hunger < 0.4 and energy > 0.6 and boredom < 0.4:
        return "neutral"  # interface rule, not a network output
    return actions[prediction]

2 | Suma ponderada

¿Qué calcula una neurona artificial?

Una neurona multiplica cada entrada por un peso, suma un sesgo y transforma el resultado mediante una función de activación. Los pesos controlan la influencia de cada entrada; el sesgo desplaza la suma.

z = x₁w₁ + x₂w₂ + x₃w₃ + b
ReLU(z) = max(0, z)

Con entradas 0.8, 0.2, 0.5; pesos 0.7, -0.5, 0.3; y sesgo 0.1:

z = 0.8×0.7 + 0.2×(-0.5) + 0.5×0.3 + 0.1 = 0.71
ReLU(0.71) = 0.71

Este 0.71 es una activación, no una probabilidad del 71 % de comer. Una neurona no ha elegido la acción; la red necesita varias neuronas y tres valores de salida.

hunger, energy, boredom = 0.8, 0.2, 0.5
w1, w2, w3, bias = 0.7, -0.5, 0.3, 0.1
z = hunger * w1 + energy * w2 + boredom * w3 + bias
activation = max(0, z)
print(activation)  # 0.71

3 | 3 → 6 → 3

¿Cómo se conectan las neuronas?

Neurito tiene tres entradas, seis neuronas ocultas y tres neuronas de salida. Cada neurona oculta combina las entradas con sus propios pesos y sesgo, y aplica ReLU. La capa de salida asigna puntuaciones a Comer, Dormir y Jugar.

ParámetroFormaSignificado
W1(3, 6)3 entradas a 6 neuronas ocultas
b1(1, 6)Sesgo de cada neurona oculta
W2(6, 3)6 neuronas ocultas a 3 salidas
b2(1, 3)Sesgo de cada salida

Los pesos comienzan con valores aleatorios pequeños. La red aún no tiene un comportamiento útil aprendido: el entrenamiento ajusta pesos y sesgos a partir de ejemplos.

4 | Predicción

De las necesidades a la acción: propagación hacia adelante

La propagación hacia adelante lleva las entradas por las capas. En NumPy, @ significa multiplicación matricial. ReLU transforma los valores ocultos; Softmax convierte las tres puntuaciones finales en valores positivos que suman 1.

z1 = data @ W1 + b1
a1 = relu(z1)
z2 = a1 @ W2 + b2
probabilities = softmax(z2)
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)

Si las salidas son Comer 0.70, Dormir 0.20 y Jugar 0.10, el modelo elige Comer porque tiene el valor mayor. Son probabilidades del modelo, no garantías ni medidas del hambre. argmax selecciona el índice de la salida mayor.

Dos tareas distintas: ReLU agrega una transformación no lineal en la capa oculta; Softmax hace comparables los resultados finales.

5 | Aprender con ejemplos

¿Cómo cambia la red durante el entrenamiento?

El proyecto genera 3000 filas sintéticas con necesidades aleatorias. Una política sencilla produce las etiquetas al comparar hambre, cansancio (1 - energía) y aburrimiento. La red practica reproducir estas respuestas; la regla que crea etiquetas no selecciona la acción durante el juego.

np.random.seed(42)
X = np.random.rand(3000, 3)
needs = np.column_stack((X[:, 0], 1 - X[:, 1], X[:, 2]))
y = np.argmax(needs, axis=1)

La semilla permite repetir la muestra. Si la energía vale 0.1, el cansancio vale 0.9; la etiqueta es Dormir si 0.9 es la prioridad mayor. La entropía cruzada mide cuánta probabilidad asigna el modelo a la respuesta correcta. La retropropagación usa derivadas y la regla de la cadena para calcular cambios; el descenso de gradiente actualiza los pesos para reducir la pérdida.

w_nuevo = w_anterior - η × ∂L/∂w

La tasa de aprendizaje η controla el tamaño del paso; no es un porcentaje de información aprendida. Una época recorre todos los ejemplos. El proyecto de referencia usa 1200 épocas y actualizaciones de lote completo.

6 | Probar casos nuevos

¿Qué nos dice una precisión alta?

Después del entrenamiento, el modelo predice 1000 situaciones recién generadas. Las predicciones se comparan con etiquetas de la misma política sintética.

test_data = np.random.rand(1000, 3)
expected = label_policy(test_data)
predicted = np.argmax(predict(test_data), axis=1)
accuracy = np.mean(predicted == expected)
print(f"Accuracy: {accuracy:.2%}")

Una precisión del 99.4 % significaría 994 coincidencias en 1000 casos de prueba. Muestra cuánto imita el modelo esta política en casos sintéticos nuevos. No demuestra inteligencia general, conocimiento de una mascota real ni que la política sea adecuada.

La evaluación depende de la respuesta esperada. Una precisión alta puede significar que el modelo aprendió muy bien una regla simplista.

Runnable example

Complete program: train the network and animate Neurito

This self-contained example trains a 3–6–3 network, evaluates it, loads the supplied sprites, and connects predictions to a Pygame window. Choose the interface language on the LANGUAGE line.

Show complete Python program
from pathlib import Path

import numpy as np
import pygame

LANGUAGE = "en"  # Change to "es" for Spanish interface text.
TEXT = {
    "en": {
        "title": "NEURITO - MY ARTIFICIAL BRAIN",
        "hunger": "Hunger", "energy": "Energy", "boredom": "Boredom",
        "eat": "EAT", "sleep": "SLEEP", "play": "PLAY", "neutral": "CALM",
        "accuracy": "Test accuracy against synthetic policy",
        "epoch": "Epoch", "loss": "Loss",
        "controls1": "H/J: hunger +/-    E/D: energy +/-",
        "controls2": "A/S: boredom +/-    R: random",
        "controls3": "N: calm state    ESC: quit",
    },
    "es": {
        "title": "NEURITO - MI CEREBRO ARTIFICIAL",
        "hunger": "Hambre", "energy": "Energía", "boredom": "Aburrimiento",
        "eat": "COMER", "sleep": "DORMIR", "play": "JUGAR", "neutral": "NEUTRAL",
        "accuracy": "Precisión frente a la política sintética",
        "epoch": "Época", "loss": "Pérdida",
        "controls1": "H/J: hambre +/-    E/D: energía +/-",
        "controls2": "A/S: aburrimiento +/-    R: aleatorio",
        "controls3": "N: estado tranquilo    ESC: salir",
    },
}
labels = TEXT[LANGUAGE]
actions = ("eat", "sleep", "play")

# Synthetic examples follow a simple priority policy.
np.random.seed(42)
X = np.random.rand(3000, 3)
targets = np.argmax(np.column_stack((X[:, 0], 1 - X[:, 1], X[:, 2])), axis=1)
W1 = np.random.randn(3, 6) * 0.5
b1 = np.zeros((1, 6))
W2 = np.random.randn(6, 3) * 0.5
b2 = np.zeros((1, 3))


def relu(values):
    return np.maximum(0, values)


def softmax(values):
    exp_values = np.exp(values - np.max(values, axis=1, keepdims=True))
    return exp_values / np.sum(exp_values, axis=1, keepdims=True)


def predict(data):
    hidden = relu(data @ W1 + b1)
    return softmax(hidden @ W2 + b2)


# Full-batch gradient descent.
for epoch in range(1200):
    z1 = X @ W1 + b1
    hidden = relu(z1)
    probabilities = softmax(hidden @ W2 + b2)
    count = len(X)
    loss = -np.mean(np.log(probabilities[np.arange(count), targets] + 1e-10))
    delta2 = probabilities.copy()
    delta2[np.arange(count), targets] -= 1
    delta2 /= count
    grad_W2 = hidden.T @ delta2
    grad_b2 = np.sum(delta2, axis=0, keepdims=True)
    delta1 = (delta2 @ W2.T) * (z1 > 0)
    grad_W1 = X.T @ delta1
    grad_b1 = np.sum(delta1, axis=0, keepdims=True)
    W1 -= 0.1 * grad_W1
    b1 -= 0.1 * grad_b1
    W2 -= 0.1 * grad_W2
    b2 -= 0.1 * grad_b2
    if epoch % 200 == 0:
        print(f"{labels['epoch']} {epoch} | {labels['loss']}: {loss:.4f}")

test = np.random.rand(1000, 3)
test_targets = np.argmax(
    np.column_stack((test[:, 0], 1 - test[:, 1], test[:, 2])), axis=1
)
accuracy = np.mean(np.argmax(predict(test), axis=1) == test_targets)
print(f"{labels['accuracy']}: {accuracy:.2%}")

pygame.init()
screen = pygame.display.set_mode((900, 600))
pygame.display.set_caption("Neurito")
clock = pygame.time.Clock()
font = pygame.font.SysFont(None, 30)
small_font = pygame.font.SysFont(None, 23)
asset_dir = Path(__file__).resolve().parent / "assets"
pet_size = (330, 330)


def load_frames(names):
    return [
        pygame.transform.smoothscale(
            pygame.image.load(str(asset_dir / name)).convert_alpha(), pet_size
        )
        for name in names
    ]


frames = {
    "neutral": load_frames(["neutral_1.png", "neutral_2.png", "neutral_3.png"]),
    "eat": load_frames(["comer_1.png", "comer_2.png"]),
    "sleep": load_frames(["dormir_1.png", "dormir_2.png"]),
    "play": load_frames(["jugar_1.png", "jugar_2.png"]),
}
needs = [0.2, 0.9, 0.2]
current_state = "neutral"
frame_index = 0
last_frame_time = pygame.time.get_ticks()
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_h:
                needs[0] = min(1, needs[0] + 0.1)
            elif event.key == pygame.K_j:
                needs[0] = max(0, needs[0] - 0.1)
            elif event.key == pygame.K_e:
                needs[1] = min(1, needs[1] + 0.1)
            elif event.key == pygame.K_d:
                needs[1] = max(0, needs[1] - 0.1)
            elif event.key == pygame.K_a:
                needs[2] = min(1, needs[2] + 0.1)
            elif event.key == pygame.K_s:
                needs[2] = max(0, needs[2] - 0.1)
            elif event.key == pygame.K_r:
                needs = list(np.random.rand(3))
            elif event.key == pygame.K_n:
                needs = [0.2, 0.9, 0.2]

    probabilities = predict(np.array([needs]))[0]
    action = actions[int(np.argmax(probabilities))]
    if needs[0] < 0.4 and needs[1] > 0.6 and needs[2] < 0.4:
        state = "neutral"  # Display rule; the network has three outputs.
    else:
        state = action

    now = pygame.time.get_ticks()
    if state != current_state:
        current_state, frame_index, last_frame_time = state, 0, now
    elif now - last_frame_time >= 500:
        frame_index = (frame_index + 1) % len(frames[state])
        last_frame_time = now

    screen.fill((250, 245, 252))
    title = font.render(labels["title"], True, (55, 45, 75))
    screen.blit(title, (45, 28))

    colors = [(235, 125, 75), (70, 175, 115), (105, 125, 225)]
    for index, key in enumerate(("hunger", "energy", "boredom")):
        value = needs[index]
        y = 125 + index * 95
        text = small_font.render(
            f"{labels[key]}: {value * 100:.0f}%", True, (35, 40, 55)
        )
        screen.blit(text, (50, y - 27))
        pygame.draw.rect(screen, (215, 220, 230), (50, y, 290, 22), border_radius=7)
        pygame.draw.rect(
            screen, colors[index], (50, y, int(290 * value), 22), border_radius=7
        )

    pet = frames[state][frame_index]
    screen.blit(pet, pet.get_rect(center=(650, 235)))
    screen.blit(font.render(labels[state], True, (65, 50, 85)), (585, 420))
    for index, action_name in enumerate(actions):
        score = small_font.render(
            f"{labels[action_name]}: {probabilities[index] * 100:.1f}%",
            True, (55, 50, 75)
        )
        screen.blit(score, (50, 390 + index * 28))

    screen.blit(small_font.render(labels["controls1"], True, (70, 70, 90)), (50, 495))
    screen.blit(small_font.render(labels["controls2"], True, (70, 70, 90)), (50, 525))
    screen.blit(small_font.render(labels["controls3"], True, (70, 70, 90)), (50, 555))
    pygame.display.flip()
    clock.tick(30)

pygame.quit()
